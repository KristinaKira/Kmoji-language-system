# K-Moji Language Syntax System

An original affective language system encoding emotional states through positional symbol grammar, created by Kristina Leticia Rodriguez.

K-Mojis compress sentence-length descriptions of human affect into compact 3-15 character symbolic expressions: micro-packets of structured affective data. The system uses a modular grammar in which no symbol carries fixed meaning in isolation; meaning is determined entirely by position and pairing, enabling a combinatorially large expression space from a compact symbol set.

## Contents

- **KMoji_Working_Paper_Rodriguez_2026 - (In preparation)** - Working paper describing the system architecture, affective resolution properties, human and AI acquisition characteristics, emergent generative behavior, and limitations.
- **KMoji_Syntax_Spec_v1.0.8.md** - Current formal syntax specification (v1.0.8).
- **kmoji_parser.py** - Working Python parser implementing the v1.0.7 specification.

## Version note

The syntax specification is currently at v1.0.8. The parser implements v1.0.7; an update to the 1.0.8 specification is planned. Version 1.0.6 included a gesture extension that was shelved for rule-complexity reasons and is documented as a candidate for a future 2.0 specification.
